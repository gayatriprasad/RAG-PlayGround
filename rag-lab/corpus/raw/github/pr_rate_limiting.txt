## Description
Implements configurable rate limiting middleware for all API endpoints. Uses sliding window algorithm backed by Redis.

## Changes
- Added `pkg/middleware/ratelimit.go` — core rate limiter implementation
- Added `pkg/middleware/ratelimit_test.go` — unit tests (94% coverage)
- Modified `cmd/api/server.go` — register middleware in chain
- Added `configs/ratelimit.yaml` — per-endpoint configuration
- Updated `docs/api/rate-limiting.md` — public documentation

## Configuration Format
```yaml
rate_limits:
  default:
    requests_per_minute: 60
    burst: 10
  endpoints:
    /api/v2/auth/login:
      requests_per_minute: 5
      burst: 2
      key: ip
    /api/v2/search:
      requests_per_minute: 30
      burst: 5
      key: user_id
    /api/v2/export:
      requests_per_minute: 2
      burst: 1
      key: org_id
```
