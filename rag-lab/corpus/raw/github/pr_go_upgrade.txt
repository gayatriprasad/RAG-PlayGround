# Pull Request: Migrate User Service to Go 1.21

**PR #1189** | Author: @james-wu | Branch: `james/PLAT-845-go-upgrade`

## Description
Upgrades user-service from Go 1.19 to Go 1.21. Adopts new standard library features including `slog` for structured logging and `slices` package.

## Key Changes
- Updated `go.mod` to Go 1.21
- Replaced `logrus` with `log/slog` (structured logging)
- Replaced custom slice utilities with `slices` package
- Adopted `maps` package for map operations
- Updated CI pipeline Go version
- Removed 3 deprecated dependency packages

## Migration Notes
- `slog` provides 40% faster logging compared to logrus in benchmarks
- All log outputs now JSON-structured by default
- Log levels: DEBUG, INFO, WARN, ERROR (configured via `LOG_LEVEL` env var)
- Backward compatible — no API changes for consumers

## Performance Impact
- Binary size: reduced 12% (18.2MB → 16.0MB)
- Startup time: improved 8% (cold start 1.2s → 1.1s)
- Memory usage: reduced 5% at steady state
- Logging throughput: 40% faster (benchmarked)

## Testing

- Added 28 new tests for slog integration
- Staging deployment: ran 72 hours with no issues
- Verified structured log parsing in Datadog
